Yorki Admin Guide

Quick guide for admins to create, assign, track, and close tasks inside Yorki.

Admin access: Admins can view all tasks, assign work, move cards between columns, archive tasks, and manage most day-to-day operations.

How To Submit A New Task

  1. Open Yorki and sign in.
  2. Go to Submit.
  3. Fill in the task title.
  4. Add a clear description with the work needed.
  5. Choose the assignee if someone should own the task right away.
  6. Set the priority: Low, Normal, High, or Urgent.
  7. Add a due date if needed.
  8. Add an address if the task is tied to a location.
  9. Use the checklist if the job has multiple steps.
  10. Check Send this task to Google Calendar only if it should also become a calendar event.
  11. Attach files if needed.
  12. Click Submit.

How To Manage A Task

  1. Open the board from Dashboard.
  2. Click a card to open the task detail panel.
  3. Reassign the task from the Assigned to field if needed.
  4. Edit description, due date, address, checklist, or calendar sync using Edit details.
  5. Add comments for updates, instructions, or notes.
  6. Move the task to another column or drag it on the board.

How To Complete, Reopen, Archive, Or Delete

  • Mark Complete: Sends the task to the completed state.
  • Reopen: Moves a completed task back to active work.
  • Archive: Sends the task out of the active board and into Archive.
  • Delete: Permanently removes the task. Use carefully.

Good Admin Habits

  • Always assign an owner when possible.
  • Use clear titles so cards are easy to scan on the board.
  • Only enable calendar sync when a real date and time matter.
  • Archive finished tasks instead of deleting them unless they are no longer needed.
